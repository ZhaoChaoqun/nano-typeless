### ASR 常见同音混淆词对

这些词对是 ASR 在无上下文时经常混淆的：

| 做 / 作 | zuò | 做=具体行为，作=抽象行为/创作 |

> **注意**：同音混淆词需要上下文语义才能区分，不适合用简单的词典替换。这部分应交给 CSC 模型或 Cloud Rewrite LLM 处理，不纳入 TermNormalizer。

## 扩充策略

TermNormalizer 是**确定性规则引擎**，只处理不需要上下文的、确定性的映射。以下是适合纳入的规则类型：

### 适合纳入的

1. **英文缩写折叠** — ASR 会把缩写展开成 `A P I` 形式，100% 确定性
2. **品牌/产品名拼写** — `chatgpt` → `ChatGPT`，不存在歧义
3. **英文术语大小写** — `github` → `GitHub`，确定性映射
4. **中文品牌名** — 不做纠错，只做 casing 类规则（如 `bilibili` → `bilibili`）

### 不适合纳入的

1. **同音混淆词** — 需要上下文，交给 CSC/LLM
2. **口语赘词去除** — `那个`、`呃`，交给 Cloud Rewrite
3. **语法纠错** — `的/得/地` 混用，交给 LLM
