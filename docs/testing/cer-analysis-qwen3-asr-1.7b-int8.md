## 关键发现

1. **总体准确度优秀**：平均 CER 0.032，184 条中 135 条完全正确 (CER=0)，73.4% 完美识别
2. **数字 ITN 是最大痛点**：模型输出中文读法而非阿拉伯数字（`192.168.1.100` → `幺九二...`），需要 ITN 后处理
3. **专有名词/品牌名误识**：`Vercel`、`Nginx`、`Ollama`、`bilibili` 等不常见品牌名容易被误识，可通过 TermNormalizer 热词映射缓解
4. **离线长音频截断问题**：`long_60s_01` (75s) 在离线模式 CER=0.296，但流式模式仅 0.047，说明超长音频应使用流式模式
5. **流式繁体字 bug**：`conv_zh_001` 流式输出了繁体中文（`銀行帳戶`），这是一个需要排查的 bug
6. **标点差异贡献了大量低 CER**：很多 0.01~0.10 的 CER 仅因为标点位置/类型不同
